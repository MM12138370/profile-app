# 职面助手

AI native 求职工具。React Native + TypeScript，仅 iOS。无服务端，数据全在本地。AI 用 TypeScript LangGraph 工作流。

交互由实现 agent 设计，本文只约束数据与能力。

---

## 本地数据

```
{存储根}/
  users.json                 # [{ hashid, username }]
  datas/
    {hashid}/
      profile.json
      jobs/
        {jobId}.json         # 该岗位的 JD / 问答 / 生成项目 / 面试结果
```

登录只输入用户名：已有则进入对应目录；没有则生成 hashid、写入注册表并创建 `datas/{hashid}/`。

---

## 1. 个人简历

`profile.json`：个人信息 + 递归板块数组。

个人信息：姓名、性别、出生年月、手机号、邮箱、学历信息、求职意向、教育经历、工作年限、意向城市。

板块数组：元素是条目 `{ title, content }`，或同构子数组。用来写工作经历、项目经历、掌握技能等。外部数据要并入简历时必须同构。

---

## 2. 求职中心

粘贴一段 JD。三项可分开触发，结果写入该岗位的 `jobs/{jobId}.json`。面试问答、相关项目都根据 **JD 结构化结果** 生成。

| 能力 | 输入 | 结果 |
|------|------|------|
| JD 结构化 | JD 正文 | 职位名称、工作年限、工作地点、岗位 JD |
| 面试问答生成 | 该岗位的结构化结果 | `[{ question, answer }]`，可编辑 |
| 相关项目生成 | 该岗位的结构化结果 | 递归数组，元素均为 `{ title, content }`，与简历板块同构，便于插入简历 |

---

## 3. 面试助手

选求职中心的一个岗位，模拟面试官问答。结束后把问题数组、标准答案数组、面试者回答数组交给 AI：打分、优化点、对该岗位匹配度（1–10）。结果写回该 job 文件。

---

## LangGraph 工作流

1. JD 正文 → 结构化字段
2. 结构化结果 → 问答数组
3. 结构化结果 → 相关项目
4. 模拟面试官
5. 面试复盘（三数组 → 评分、优化点、匹配度）

禁止编造用户没有的经历、数据、技能。

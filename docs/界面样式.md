# 界面样式

只记版式、位置、文案和区块长什么样。不含跳转、校验、存储、接口。

视觉基调：暖纸底、铁锈强调色、少装饰。一屏只做一件事。登录后先停在欢迎页，再进主壳。

---

## 视觉基调

| 角色 | 色 | 用途 |
|------|----|------|
| 纸底 | `#F3F0EA` | 全屏底 |
| 卡片 | `#FFFBF4` | 列表行、输入、分段轨道 |
| 正文 | `#1A1714` | 标题、列表名 |
| 次文 | `#6F675E` | 语录、说明 |
| 弱文 | `#A39A90` | 辅助、未选中 Tab |
| 强调 | `#B44A2A` | 主按钮、当前分段、当前 Tab |
| 线 | `#E6DFD4` | 分割、描边 |

字号：欢迎名 32 / 语录 16；列表名 17；空态大按钮 18；辅助 13。  
行距略松。左右留白 20。圆角 14–20。顶栏图标 24，左右对称。

---

## 欢迎页

登录成功、或进程被清后再打开：先落这一屏。无顶栏、无底栏、无按钮。浅底，垂直居中略偏上。

```
            {昵称}，欢迎您！

            {一段励志语录}
```

- 第一行：字重高、正文色。无昵称时，用账号四位数字代替昵称。
- 第二行：次文色，单段，宽度不超过屏宽的 70%，居中。
- 两行间距约 20。停两拍后进入主壳；轻点也可进入。进过后台再回前台：不停在本页、不换语录。

---

## 主壳

三 Tab 共用同一顶栏。内容区不重复写大标题——底栏已经说明在哪。

```
┌────────────────────────────────┐
│  [+]                      [齿轮] │
│                                │
│             内容区              │
│                                │
├────────────────────────────────┤
│  简历中心 │ 岗位列表 │ 面试助手  │
└────────────────────────────────┘
```

- **右上**：齿轮，三 Tab 都在。
- **左上**：`+`。仅当前列表已有数据时出现；空屏只用内容区那颗大按钮。
- **底栏**：简历中心 / 岗位列表 / 面试助手。当前项强调色，其余弱文。无顶部分割线以外的装饰。

`+` 跟当前列表走：已导入简历 → 再导一份简历；简历模板 → 再导一份模板；岗位列表 → 再导一个岗位。面试助手没有 `+`。

---

## 顶栏分段（仅简历中心）

顶栏下方一条轨道，两格等宽，一次只亮一格。两套列表分开展示，不混排。

```
┌────────────────────────────────┐
│  [+]                      [齿轮] │
│  ┌────────────┬────────────┐   │
│  │ 已导入简历  │  简历模板   │   │
│  └────────────┴────────────┘   │
│             内容区              │
└────────────────────────────────┘
```

亮着的格：卡片底 + 强调字。未亮：透明 + 弱文。

---

## 空屏 / 有内容

空：内容区正中一颗 **大按钮**（约 72% 宽，大圆角，强调底、白字）。  
有内容：列表顶对齐；大按钮收起，改用左上角 `+`。

| 屏 | 空 · 大按钮 | 有内容 |
|----|-------------|--------|
| 已导入简历 | 导入简历 | 简历列表 |
| 简历模板 | 导入模板 | 模板列表 |
| 岗位列表 | 导入岗位 | 岗位列表 |
| 面试助手 | 选择岗位模拟面试 | 岗位列表（再选简历） |

缺数据提示（居中一句，可跟一颗小按钮）：

- 暂无简历，去导入
- 去岗位列表导入（无岗位时）

## 设置

齿轮进入。整页留白多，只有两块，不要网格和多余分组。

```
┌────────────────────────────────┐
│  修改昵称                       │
│  ┌──────────────────────────┐  │
│  │                          │  │
│  └──────────────────────────┘  │
│            [保存]               │
│                                │
│          [退出登录]             │
└────────────────────────────────┘
```

退出用危险色描边/字，不要做成和保存一样的主按钮。

## 弹窗

### 命名确认

导入后先弹出。标题一句，右下两颗字按钮，无大段说明。

```
  是否以「xxx」命名？

              [否]    [是]
```

- 是：用该名
- 否：同一流程改成单行输入名称

`xxx` 只改默认文案，不改弹窗样子：

- 简历 PDF：文件名（去掉 `.pdf`）
- 岗位：解析出的职位名；解析不到则跳过本弹窗，直接手输

### 粘贴链接

岗位导入用同一窗口，一张卡片：

- 主输入：粘贴链接
- 失败时同一窗口改成：粘贴 JD 正文

---

## 列表

一项一行：左主名，下可跟一行次文，右极弱 chevron。行与行之间细线或 8–10 的间隙。点按进入下一级。支持左滑删除。

| 列表项 | 进入后 |
|--------|--------|
| 已导入简历 | **预览**（统一版式） |
| 简历模板 | **直接编辑**（不经过预览） |
| 岗位 | 先选简历，再出匹配报告 |

---

## 简历预览（统一版式）

整页按模块自上而下，模块名小写强调色，内容正文色。v1 只这一套。底栏固定一颗按钮，不随滚动走丢：

`不满意，去修改`

### 模块顺序

1. 基本信息（姓名、求职意向、城市、年限、电话、邮箱、链接）
2. 教育经历
3. 工作 / 实习经历
4. 项目经历
5. 技能
6. 其他（证书等，可空）
7. 自我评价（可空）
8. 未识别原文（可空）

空模块整块不画，不留「暂无」。编辑页、导出版式与预览同一套顺序。编辑页另有一颗 **AI 润色**，位置在底栏按钮上方。

---

## 匹配报告

自上而下，分数最大，其余模块同预览的小标题节奏：

1. **综合匹配分** `0–100`（大数字，居中或左顶）
2. **结论** 三档之一：`较高` / `中等需改` / `差距明显`
3. **技能对齐**（具备 / 经历可支撑 / 未见）
4. **匹配点**
5. **缺口**
6. **优化清单**

---

## 面试

v1 纯文字。加压追问默认开，界面不放开关。

### 进行中

一轮区块顺序（问完即结束，可随时停）。当前问在上，回答框贴底。

```
自我介绍
  → 经历深挖
  → JD 专业题
  → 情景
  → 加压追问
  → 收尾
```

### 评分报告

1. **总分** `0–100`
2. **雷达** 五轴：逻辑、技术/专业能力、沟通、岗位匹配、应变
3. **逐题点评**
4. **改简历回流**（入口/清单区）

---

## 注册 / 登录

无底栏。上疏下紧：产品名在上，表单居中。

- 账号：4 位数字
- 密码：6 位数字
- 昵称：可选，占位「怎么称呼你（可选）」
- 主按钮：进入 / 注册（按是否已有账号只出现一个词）

# 职面助手

iOS 求职工具：把简历改清楚，对照岗位看匹配，再按该岗位练面试。  
技术：React Native + TypeScript，仅 iOS。v1 免费。  
数据：第一期全部走用户后端，客户端不作为主库。

---

## 产品结构

```
注册 / 登录
    └── 主壳（右上角齿轮 = 设置）
            ├── 欢迎页（仅冷启动）
            ├── 简历中心（顶栏：已导入简历 | 简历模板）
            ├── 岗位列表
            └── 面试助手
```

主壳：右上角齿轮；有列表数据时 **左上角 +**；底部 Tab：**简历中心 / 岗位列表 / 面试助手**。

**各 Tab 第一屏：**

| Tab | 空 | 有内容 |
|-----|----|--------|
| 简历中心 · 已导入简历 | 大按钮：导入简历 | 简历列表；+ 只导入简历。点一项 → **预览** |
| 简历中心 · 简历模板 | 大按钮：导入模板 | 模板列表；+ 只导入模板。点一项 → **直接编辑**（不进预览） |
| 岗位列表 | 大按钮：导入岗位 → 粘贴链接窗口 | 岗位列表；+ 同一窗口。点一项 → 选简历 → 匹配报告 |
| 面试助手 | 大按钮：选择岗位模拟面试 | 选岗位 → 选简历 → 开面。缺数据则提示去对应 Tab |

**欢迎页：**

```
{昵称}，欢迎您！
{一段 AI 励志语录}
```

未填昵称时用账号四位数字。仅 **登录成功** 或 **进程被清后再次打开** 出现。进过后台再回前台：停在离开页，不刷新语录。

### 设置

齿轮里 **只有**：修改昵称、退出登录。

---

## 账号

- 未登录不能用三个模块。杀进程后 **保持登录**，再打开先出欢迎页。
- 账号：4 位数字（自选，占用则换一个）
- 密码：6 位数字
- 昵称：注册可选，中/英，设置里可改

---

## 命名确认（简历 / 岗位共用交互）

导入后先弹出：「是否以「xxx」命名？」

- 是 → 用这个名字进列表
- 否 → 手动输入名称再进列表

**xxx 从哪来：**

- **简历 PDF：** 该文件名（去掉 `.pdf`）
- **岗位：** 链接解析出的职位名；解析不到则跳过「是否」直接手输（岗位是粘贴链接，没有 PDF）

---

## 1. 简历中心

顶栏两个按钮，**列表分开，不混排**：

- **已导入简历**
- **简历模板**

左上角 `+` 只跟当前顶栏走：在简历页就导简历，在模板页就导模板。

### 已导入简历

1. 选 PDF → 命名确认（默认文件名）→ 解析 → 校对 → 保存进本列表  
2. **点一项先进预览**（统一版式）  
3. 预览下方按钮：**不满意，去修改** → 进入编辑  
4. 编辑页提供 **AI 润色**（一键润色当前简历，不针对某个 JD）  
5. 编辑保存后仍只出现在「已导入简历」

### 简历模板

1. 导入 PDF 模板，进模板列表  
2. **点击不进预览，直接编辑**（按该模板填内容）  
3. **保存 / 导出** 的结果是一份新简历，**只出现在「已导入简历」**，模板列表不变

版式 v1 只落地一套系统格式。用户模板只支持 PDF，不追求 1:1 还原复杂排版。

### 简历模块（解析、编辑、导出共用）

1. 基本信息（姓名、求职意向、城市、年限、电话、邮箱、链接）  
2. 教育经历  
3. 工作 / 实习经历  
4. 项目经历  
5. 技能  
6. 其他（证书等，可选）  
7. 自我评价（可选）  
8. 未识别原文（解析残留）

校对后再保存。原文 PDF 留对照。

### 按岗位优化（从匹配报告进来）

针对「用户选的那份简历 + 该岗位」，建议重排、删减、技能对齐（具备 / 经历可支撑 / 未见）。  
**不直接覆盖**，对比确认后写入。禁止编造经历、数据、不会的技能。可回滚。

「未见」技能不能写成会有。一键润色只改已有表述，同样禁止编造。

---

## 2. 岗位列表

- 空：大按钮「导入岗位」→ 粘贴链接窗口  
- 有数据：列表 + 左上角 +（同一窗口）  
- 点一条：先选要用的简历 → 匹配报告  
- **一份简历都没有：** 提示「暂无简历，去导入」，跳到简历中心 · 已导入简历

链接只解析用户提交的这一条。失败则同一窗口改粘贴 JD 正文。不做招聘站后台抓取。

系统分享岗位 URL 进来，走同一套导入。

### 匹配报告

- 综合匹配分 0–100 + 结论（较高 / 中等需改 / 差距明显）
- 技能对齐、匹配点、缺口
- 优化清单 → 按该岗位改简历

v1 不做投递状态。列表支持左滑删除。

---

## 3. 面试助手

v1 只做文字。加压追问默认开，不做开关。

大按钮「选择岗位模拟面试」：

1. 选岗位 → 没有岗位：提示去 **岗位列表** 导入  
2. 选简历 → 没有简历：提示「暂无简历，去导入」→ **简历中心**  
3. 都有则进入该「岗位 × 简历」文字面试

问完一轮即结束（自我介绍 → 经历深挖 → JD 专业题 → 情景 → 加压追问 → 收尾），可随时停。

**评分：** 总分 0–100 + 雷达（逻辑、技术/专业能力、沟通、岗位匹配、应变）+ 逐题点评 + 改简历回流。

## 后端（第一期对接）

客户端调用用户提供的后端，至少包括：

- 注册 / 登录 / 改昵称 / 退出（清本地登录态）
- 简历 CRUD、命名、PDF 上传与解析、预览导出
- 模板 CRUD；从模板保存为新简历
- 岗位 CRUD、单条链接解析、粘贴 JD
- 匹配报告、按 JD 优化、一键润色
- 面试会话、下一问、评分
- 欢迎页语录
- AI 密钥只放服务端

---

## v1 做 / 不做

**做：** 上述主壳与三模块；命名确认；简历预览再改；模板与简历分列表；匹配/面试自选简历；缺数据提示跳转；对接用户后端。

**不做：** Android；招聘站爬虫；语音面试；支付；投递追踪；多套系统版式；设置里改密码/注销。

---

## 落地顺序

1. 工程 + 对接登录注册 + 主壳  
2. 简历中心（双顶栏、导入命名、预览/编辑、模板出简历）  
3. 岗位列表 + 选简历 + 匹配报告 + 按岗优化  
4. 文字面试 + 评分  
5. TestFlight

---

## 规则

- 不编造经历、数据、不会的技能  
- 链接解析只处理用户主动提交的单条 URL  
- 简历 / 模板 / 岗位按账号隔离；列表可左滑删除
